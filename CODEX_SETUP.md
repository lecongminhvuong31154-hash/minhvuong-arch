# ARCHITECT PERSONAL PORTFOLIO

Website portfolio cá nhân cho kiến trúc sư / thiết kế nội thất / ngoại thất.

## Cấu trúc
- index.html
- about.html
- projects.html
- project-detail.html
- documents.html
- contact.html
- css/style.css
- js/script.js
- assets/images/       -> thêm ảnh công trình
- assets/documents/    -> thêm PDF tài liệu

## Chạy trong Codex
Mở folder này trong Codex.

Có thể yêu cầu Codex:
- thay tên thương hiệu
- thay tên kiến trúc sư
- thay số điện thoại
- thay email
- thay link Facebook/TikTok/Zalo
- thay ảnh mẫu bằng ảnh thật trong assets/images
- thêm công trình mới
- thêm tài liệu PDF
- đổi màu / font / bố cục

## GitHub Pages
Upload toàn bộ folder lên repository GitHub, sau đó bật:
Settings -> Pages -> Deploy from a branch -> main -> / (root).
