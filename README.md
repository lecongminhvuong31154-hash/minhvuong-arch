# Portfolio Kiến trúc cá nhân

Website portfolio theo phong cách mộc mạc + Địa Trung Hải hiện đại.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file/thư mục trong gói này.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → `main` → `/root`.
5. Save.

## Cần thay trước khi công khai
- `ARCHITECT.` → tên thương hiệu/tên cá nhân.
- `Tên của bạn` → tên kiến trúc sư.
- Email, số điện thoại, mạng xã hội.
- Ảnh trong các khối `.image-1` đến `.image-4` bằng ảnh công trình thật.
- Các file PDF trong `assets/documents/`.
- Form liên hệ hiện là giao diện demo; muốn nhận form thật cần kết nối dịch vụ form/email.
